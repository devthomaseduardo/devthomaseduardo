## Sobre

Minha trajetória em tecnologia começou em **2023**, quando iniciei minha transição de carreira para desenvolvimento de software.

Comecei construindo interfaces, mas rapidamente percebi que uma boa tela, sozinha, não resolve um produto.

Passei a trabalhar também com:

`APIs` · `Autenticação` · `Banco de dados` · `Regras de negócio` · `Integrações` · `Deploy`

Hoje busco entender o produto como um sistema completo.

Não penso apenas em como uma interface deve parecer, mas em como os dados circulam, como as regras funcionam, como a aplicação será publicada e como ela poderá continuar evoluindo.

## Engenharia

Nos projetos mais recentes, meu foco deixou de ser somente entregar funcionalidades.

Tenho trabalhado principalmente com:

```text
Frontend
├── React
├── TypeScript
├── Next.js
└── Tailwind CSS

Backend
├── Node.js
├── Fastify
├── Express
└── NestJS

Dados
├── PostgreSQL
├── MongoDB
├── Prisma
├── Supabase
└── Firebase

Infraestrutura
├── Docker
├── Linux
├── AWS
├── Vercel
└── GitHub Actions
```

Além da implementação, venho aprofundando:

- arquitetura backend

- segurança de APIs
- modelagem de dados
- tratamento de erros
- configuração de ambientes
- integrações externas
- CI/CD
- testes
